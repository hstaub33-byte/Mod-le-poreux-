\section*{Introduction}

Ce document présente le développement d'un modèle de transport et de 
réaction dans une électrode poreuse dédiée à la réduction électrochimique
 du CO$_2$. L'objectif est de construire un modèle homogénéisé 
 unidimensionnel à partir d'une description tridimensionnelle
  à l'échelle du pore, tout en identifiant les hypothèses physiques
   nécessaires à cette réduction de modèle.

Le point de départ est un modèle 3D couplant le transport 
des espèces par Nernst–Planck, le transport électronique 
dans la phase solide, la cinétique interfaciale et la 
description du potentiel électrique. Ce modèle sert de 
cadre de référence pour analyser les hypothèses de 
simplification et développer des modèles macroscopiques adaptés.

Après la présentation du modèle microscopique et de ses hypothèses,
 une analyse adimensionnelle est menée afin d'identifier les régimes 
 physiques dominants. Deux approches de réduction sont ensuite présentées :
  une première fondée sur le module de Thiele, puis une approche plus générale 
  basée sur l'homogénéisation par prise de moyenne volumique. Le document se conclut 
  par une discussion des simulations envisagées pour valider les modèles obtenus.
