\section*{Modèle retenu : application au CO$_2$ et CO}

Dans un premier temps, on retient le modèle réduit obtenu à partir de
l'approche de Thiele. Le transport est supposé purement diffusif, le
système est considéré en régime stationnaire, et les effets de migration,
de convection et de chute ohmique sont négligés~\cite{blakeAnalyticalModellingCO2021}.

On considère uniquement deux espèces : le CO$_2$, consommé par la
réaction, et le CO, produit par cette même réaction. La réaction globale
est représentée sous la forme simplifiée :
\begin{equation}
\mathrm{CO_2 \longrightarrow CO}.
\end{equation}

Dans cette section, les concentrations désignent les grandeurs moyennées
dans la phase liquide du milieu poreux. On note donc
$\left\langle C_{\ce{CO2}}\right\rangle^l$ et
$\left\langle C_{\ce{CO}}\right\rangle^l$ les concentrations moyennes de
\ce{CO2} et de \ce{CO}.

Cette écriture ne décrit pas explicitement les espèces ioniques, l'eau,
ni les intermédiaires réactionnels. Elle sert uniquement à construire un
premier modèle diffusion--réaction pour les deux espèces carbonées.

Le système étudié est donc :
\begin{equation}
\begin{cases}
\varepsilon_l D_{\ce{CO2}}^{\mathrm{eff}}
\dfrac{d^2 \left\langle C_{\ce{CO2}}\right\rangle^l}{dz^2}
=
a_v^{\mathrm{cat}}
k_r(\eta_{\mathrm{ref}})
\left\langle C_{\ce{CO2}}\right\rangle^l,
\\[0.4cm]
\varepsilon_l D_{\ce{CO}}^{\mathrm{eff}}
\dfrac{d^2 \left\langle C_{\ce{CO}}\right\rangle^l}{dz^2}
=
-
a_v^{\mathrm{cat}}
k_r(\eta_{\mathrm{ref}})
\left\langle C_{\ce{CO2}}\right\rangle^l.
\end{cases}
\end{equation}

Le signe positif au second membre de l'équation du \ce{CO2} traduit sa
consommation, le signe négatif pour le \ce{CO} sa production, les deux espèces
étant couplées par la stœchiométrie $1:1$ de la réaction.

Avec la coordonnée adimensionnée $\zeta$ et le module de Thiele $\phi$
définis précédemment, le système s'écrit :
\begin{equation}
\begin{cases}
\dfrac{d^2 \left\langle C_{\ce{CO2}}\right\rangle^l}{d\zeta^2}
=
\phi^2
\left\langle C_{\ce{CO2}}\right\rangle^l,
\\[0.4cm]
\dfrac{d^2 \left\langle C_{\ce{CO}}\right\rangle^l}{d\zeta^2}
=
-
\dfrac{
a_v^{\mathrm{cat}}
k_r(\eta_{\mathrm{ref}})
l_e^2
}{
\varepsilon_l D_{\ce{CO}}^{\mathrm{eff}}
}
\left\langle C_{\ce{CO2}}\right\rangle^l.
\end{cases}
\end{equation}

On impose une concentration fixée à l'interface avec le bulk et un flux
nul à la paroi :

\begin{align}
\left\langle C_{\ce{CO2}}\right\rangle^l(0) &= C_{\ce{CO2}}^{\mathrm{hom}},
&
\frac{d \left\langle C_{\ce{CO2}}\right\rangle^l}{d\zeta}(-1) &= 0,\\
\left\langle C_{\ce{CO}}\right\rangle^l(0) &= C_{\ce{CO}}^{\mathrm{hom}},
&
\frac{d \left\langle C_{\ce{CO}}\right\rangle^l}{d\zeta}(-1) &= 0.
\end{align}

La solution analytique pour le CO$_2$ est :

\begin{equation}
\boxed{
\left\langle C_{\ce{CO2}}\right\rangle^l(\zeta)
=
C_{\ce{CO2}}^{\mathrm{hom}}
\frac{
\cosh\!\left[\phi(\zeta+1)\right]
}
{\cosh(\phi)}
}
\end{equation}

Le CO étant produit localement à partir de la consommation du CO$_2$,
son profil est obtenu en injectant la solution précédente dans l'équation
de conservation du CO. On obtient :

\begin{equation}
\boxed{
\left\langle C_{\ce{CO}}\right\rangle^l(\zeta)
=
C_{\ce{CO}}^{\mathrm{hom}}
+
\frac{D_{\ce{CO2}}^{\mathrm{eff}}}
     {D_{\ce{CO}}^{\mathrm{eff}}}
C_{\ce{CO2}}^{\mathrm{hom}}
\left[
1-
\frac{
\cosh\!\left[\phi(\zeta+1)\right]
}
{\cosh(\phi)}
\right]
}
\end{equation}

Ce modèle constitue le premier cas test retenu pour les simulations.
Il permet d'étudier l'influence du module de Thiele sur la pénétration
du CO$_2$ dans l'électrode et sur la formation locale de CO.
